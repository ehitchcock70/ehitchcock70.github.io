Storage Setup

Create a ZFS Pool

How To

  1. Go to Storage → Create Pool.
  2. Choose a layout: Mirror for 2 disks or RAIDZ1/RAIDZ2 for 3+ disks.
  3. Add the data disks and confirm.
  4. Schedule scrubs to detect silent corruption.
  5. Schedule SMART tests to catch failing drives early.
ZFS RAIDZ

Datasets & Permissions

How To

  1. Create separate datasets: media, backups, lab-isos, documents.
  2. Create local users and groups under Credentials.
  3. Set ACLs so each group only reaches the datasets it needs.
  4. Share with SMB; leave SMB1 disabled.

Hardening & Protection

Secure the Server

  • Enable two factor authentication for the admin account.
  • Keep SSH disabled unless needed; use keys, not passwords.
  • Bind the web UI to the LAN interface only and use HTTPS.
  • Configure email alerts for pool, disk, and update events.
  • Apply TrueNAS updates on a regular schedule.
2FA Alerting

Ransomware Protection

  • Periodic snapshot tasks on every dataset (hourly and daily).
  • Snapshots are read only, so encrypted files can be rolled back.
  • Replicate snapshots to a second system or offsite target.
  • Follow the 3-2-1 rule: 3 copies, 2 media types, 1 offsite.
