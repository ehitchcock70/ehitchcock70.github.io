Microsoft Intune

Compliance Policy

How To

  1. Go to Devices → Compliance → Create policy.
  2. Require BitLocker, Secure Boot, and a minimum OS version.
  3. Require Defender real time protection to be on.
  4. Set actions for noncompliance (notify, then mark noncompliant).
  5. Pair with Conditional Access to block noncompliant devices.

Kandji (macOS)

Blueprint Setup

How To

  1. Connect Apple Business Manager for Automated Device Enrollment.
  2. Create a Blueprint for each device group.
  3. Add Library Items: FileVault, firewall, passcode, and screen lock.
  4. Add Auto Apps for standard software.
  5. Enable security Parameters aligned to CIS benchmarks.

Microsoft Defender

Attack Surface Reduction

How To

  1. Onboard devices to Defender for Endpoint through Intune.
  2. Create an ASR policy under Endpoint security.
  3. Start rules in Audit mode and review the reports.
  4. Move to Block once false positives are handled.
  5. Key rule: block credential stealing from LSASS.
