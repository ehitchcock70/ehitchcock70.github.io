KQL

Hands on analysis of security logs using Kusto Query Language to detect and investigate threats efficiently.

Core Operators

  • where filters rows
  • project selects columns
  • summarize aggregates (count, dcount)
  • extend creates calculated columns
  • join combines tables
  • sort by / top orders results
  • render builds charts
Query Basics

Failed Sign In Spike

Find accounts with repeated failed Entra ID sign ins.

SigninLogs
| where TimeGenerated > ago(1d)
| where ResultType != "0"
| summarize Failures = count()
    by UserPrincipalName, IPAddress
| where Failures > 10
| sort by Failures desc
Brute Force

Windows Logon Failures

Event ID 4625 grouped by target account and source.

SecurityEvent
| where EventID == 4625
| summarize Attempts = count()
    by TargetAccount, IpAddress, Computer
| top 20 by Attempts
Windows Events

Visualize Alerts by Severity

Quick chart of alert volume over the last week.

SecurityAlert
| where TimeGenerated > ago(7d)
| summarize count() by AlertSeverity
| render piechart

Microsoft Defender XDR

How Defender XDR detects and responds to real world attack techniques, from initial access to lateral movement, using live lab scenarios.

Platform Overview

  • Unifies Defender for Endpoint, Office 365, Identity, and Cloud Apps.
  • Correlates alerts across products into a single incident.
  • Automated investigation and response remediates common threats.
  • Attack disruption contains compromised users and devices in progress.
XDR Unified Incidents

How To: Investigate an Incident

  1. Open Incidents & alerts in the Defender portal.
  2. Review the attack story and alert timeline.
  3. Check impacted assets: devices, users, and mailboxes.
  4. Take response actions: isolate device, collect investigation package, or run antivirus scan.
  5. Resolve and classify the incident.

Advanced Hunting: Suspicious PowerShell

Hunt for encoded PowerShell commands, a common initial access and execution technique.

DeviceProcessEvents
| where Timestamp > ago(7d)
| where FileName in~ ("powershell.exe", "pwsh.exe")
| where ProcessCommandLine has_any ("-enc", "-EncodedCommand", "FromBase64String")
| project Timestamp, DeviceName, AccountName,
          ProcessCommandLine, InitiatingProcessFileName
| sort by Timestamp desc

Azure Security Challenges

Challenge based module mixing offensive and defensive Azure tasks to sharpen real world cloud security skills.

Red Team Focus

  • Enumerate tenant resources and role assignments with Azure CLI.
  • Abuse overly permissive RBAC roles and managed identities.
  • Find exposed secrets in storage accounts, SAS tokens, and app settings.
  • Access Key Vault secrets through misconfigured access policies.
az login
az account list -o table
az role assignment list --all -o table
az storage account list -o table
Azure CLI Offensive

Blue Team Focus

  • Review Entra ID sign in and audit logs for suspicious activity.
  • Query AzureActivity for unexpected role or resource changes.
  • Apply least privilege RBAC and restrict NSG rules.
  • Use Defender for Cloud recommendations to reduce attack surface.
AzureActivity
| where OperationNameValue has
    "roleAssignments/write"
| project TimeGenerated, Caller,
    ResourceGroup, ActivityStatusValue
