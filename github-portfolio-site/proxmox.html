Architecture

The lab runs on two bridges: a management bridge connected to the home LAN, and an isolated bridge with no physical uplink so attack traffic and malware never touch the home network.

Setup How To

Install Proxmox VE

  1. Download the Proxmox VE ISO and write it to USB with Rufus or Etcher.
  2. Enable virtualization (VT-x/AMD-V) in the BIOS.
  3. Boot the installer, choose the target disk, and set a static IP.
  4. Browse to https://<host-ip>:8006 and log in.
  5. Upload ISOs under local → ISO Images.
Installation

Create an Isolated Lab Bridge

Add to /etc/network/interfaces, then run ifreload -a.

auto vmbr1
iface vmbr1 inet manual
    bridge-ports none
    bridge-stp off
    bridge-fd 0
#Isolated security lab
Networking

Create a Lab VM from the CLI

Build a Kali VM attached only to the isolated bridge.

qm create 110 --name kali-attack \
  --memory 4096 --cores 2 --ostype l26 \
  --net0 virtio,bridge=vmbr1 \
  --scsi0 local-lvm:40 \
  --ide2 local:iso/kali-linux.iso,media=cdrom \
  --boot order=scsi0;ide2
qm start 110

Hardening & Backups

Secure the Host

  1. Create a named admin account instead of using root@pam daily.
  2. Enable TOTP two factor on the web UI.
  3. Turn on the Proxmox firewall at the datacenter level.
  4. Never expose port 8006 to the internet; use a VPN.
  5. Keep the host patched with apt update && apt full-upgrade.
pveum user add eric@pve
pveum passwd eric@pve
pveum acl modify / -user eric@pve -role PVEAdmin

Snapshots & Backups

Snapshot a clean baseline before every attack exercise, then roll back after.

# Baseline before an exercise
qm snapshot 110 clean-baseline

# Reset after the exercise
qm rollback 110 clean-baseline

# Full backup to storage
vzdump 110 --mode snapshot \
  --compress zstd --storage local
