Deployment

All In One Install

How To

  1. Provision an Ubuntu server with at least 4 vCPU and 8 GB RAM.
  2. Run the assisted installer with the -a flag.
  3. Save the admin password printed at the end.
  4. Browse to https://<server-ip> and log in.
curl -sO https://packages.wazuh.com/4.x/wazuh-install.sh
sudo bash ./wazuh-install.sh -a
Installation Ubuntu

Firewall Ports

  • 1514/TCP agent event data
  • 1515/TCP agent enrollment
  • 443/TCP dashboard
  • 55000/TCP Wazuh API

Only allow these from trusted internal subnets.

Agent Onboarding

Windows Agent

Silent install pointing the agent at the manager.

msiexec.exe /i wazuh-agent.msi /q ^
  WAZUH_MANAGER="10.0.0.10" ^
  WAZUH_AGENT_NAME="WIN-WS01"
NET START WazuhSvc
Windows msiexec

Linux Agent

Install from the Wazuh repository, then enable the service.

sudo WAZUH_MANAGER="10.0.0.10" \
  apt-get install wazuh-agent
sudo systemctl enable --now wazuh-agent
Linux systemd

Detections & Tuning

Custom Brute Force Rule

Added to /var/ossec/etc/rules/local_rules.xml to escalate repeated Windows logon failures.

<group name="local,windows,">
  <rule id="100100" level="10" frequency="5" timeframe="120">
    <if_matched_sid>60122</if_matched_sid>
    <description>Multiple failed Windows logons</description>
    <mitre><id>T1110</id></mitre>
  </rule>
</group>

File Integrity Monitoring

Real time monitoring of sensitive folders in the agent ossec.conf.

<syscheck>
  <directories check_all="yes"
    realtime="yes">C:\Users\Public</directories>
</syscheck>
FIM syscheck

Tuning Tips

  • Start with default rules, then review the noisiest alerts weekly.
  • Lower or suppress known benign events instead of disabling whole groups.
  • Use Security Configuration Assessment (SCA) for CIS baseline checks.
  • Enable vulnerability detection to flag outdated packages.
